# Blinkit Sales Analysis Dashboard

Headline

Interactive Power BI Dashboard for Analyzing Blinkit Sales Performance and Customer Trends

Short Description

This project presents a comprehensive sales analysis dashboard for Blinkit, India's last-minute delivery platform. The dashboard provides insights into total sales, average sales, product performance, outlet performance, customer ratings, and inventory distribution. Interactive filters allow users to analyze sales by outlet location, outlet size, and item type, enabling data-driven business decisions.

Purpose

The main purpose of this dashboard is to:

Monitor overall sales performance across Blinkit outlets.
Identify top-performing products and outlet categories.
Analyze customer ratings and purchasing patterns.
Compare sales across outlet sizes and locations.
Support management in making informed strategic and operational decisions.
Tech Stack
Power BI – Dashboard development and data visualization
Microsoft Excel / CSV – Data storage and preprocessing
Power Query – Data cleaning and transformation
DAX (Data Analysis Expressions) – Calculated measures and KPIs
Data Modeling – Relationship management and performance optimization
Data Source

Blinkit Grocery Sales Dataset

The dataset contains:

Item details (Item Type, Fat Content, Visibility, Weight)
Outlet information (Outlet Type, Outlet Size, Location Tier, Establishment Year)
Sales metrics (Total Sales, Average Sales, Number of Items Sold)
Customer ratings and product performance indicators
